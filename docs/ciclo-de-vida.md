# Ciclo de Vida dos Requisitos – Projeto Cardápio IFRN

## 1. Estados do Ciclo de Vida

Os estados definidos para o diagrama de estados, com base nas características do projeto *Cardápio IFRN*, são os seguintes:

1. **Identificado**: Requisito foi levantado inicialmente com base nas necessidades dos usuários.
2. **Documentado**: Requisito foi escrito formalmente com descrição clara.
3. **Validado**: Requisito foi confirmado pelos stakeholders como relevante e compreendido.
4. **Aprovado**: Requisito foi aceito para desenvolvimento.
5. **Implementado**: Requisito já foi codificado no sistema.
6. **Testado**: O funcionamento do requisito foi testado.
7. **Liberado**: O requisito está em produção no sistema.
